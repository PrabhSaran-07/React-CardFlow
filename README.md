# React CardFlow

A React mini project built with Vite that demonstrates reusable components, props, state management, event handling, and dynamic rendering.

## Live Demo

(https://prabhsaran-07.github.io/React-CardFlow/)

##  About

React CardFlow is a simple interactive React application developed to practice fundamental React concepts.

The project includes:

- Dynamic contact card creation using a form
- Reusable contact card components
- A user list component for displaying contacts
- Like/Unlike functionality using React state
- Reusable cards with different titles passed through props

##  Features

###  Dynamic Contact Cards

- Add a new contact using a form
- Enter name, email, and phone number
- Dynamically generate contact cards
- Display multiple contacts
- Reusable `ContactCard` component
- `UserList` component for rendering contacts
- Basic form validation

###  Like / Unlike Cards

- Reusable `Card` component
- Different card titles using props
- Like and Unlike functionality
- Individual state for each card
- Dynamic `Liked` / `Not Liked` status
